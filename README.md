# Haseeb Ahmad — DevOps & Cloud Engineer Portfolio

A minimalist, high-performance developer portfolio showcasing enterprise cloud infrastructure, Kubernetes clusters, and automated CI/CD pipelines.

## Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Vanilla CSS (Albert Sans & Fragment Mono)
- **Animations:** Framer Motion + GPU-accelerated CSS Keyframes
- **Deployment:** Vercel

## Pages
- `/` — Architectural Minimalist Hero Landing Page
- `/about` — Engineering background, core disciplines, and platform architecture
- `/experience` — Production DevOps roles, enterprise achievements, and CI/CD lifecycles
- `/work` — Deep-dive expandable architecture projects & deliverables
- `/education` — Academic foundations, degrees, and specialized cloud certifications

## Getting Started
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
